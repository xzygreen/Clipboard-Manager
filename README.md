# 剪贴板历史 ClipboardManager

一个 macOS 菜单栏剪贴板历史管理器,原生 Swift(AppKit + SwiftUI),无需 Xcode 即可构建。

- 后台监听剪贴板,记录 **文本 / 图片 / 文件**(带来源 App 与时间)
- **⌘⇧V** 全局快捷键或点菜单栏图标唤出弹窗
- 弹窗内 **搜索过滤**、`↑↓` 选择、`↵` 选用、`⌫` 删除、右键菜单 **置顶 / 删除**
- 半透明(vibrancy)圆角悬浮面板,类型彩色徽章/图片缩略图、悬停高亮、快捷键提示条
- 自带程序化生成的 **App 图标**(`build.sh` 调 `iconutil` 自动产出)
- 选中后 **自动粘贴** 到当前窗口(默认开,需「辅助功能」权限);可在菜单关掉,改为仅复制、手动 `⌘V`
- 历史 **持久化** 到 `~/Library/Application Support/ClipboardManager/`,重启保留
- 容量上限(默认 200 条)只淘汰**非置顶**项;**置顶**项永久保留
- **忽略密码 / 敏感内容**(识别 nspasteboard 的 `Concealed` / `Transient` / `AutoGenerated` 标记,密码管理器会打标)
- 列表针对**大量条目**优化:行内悬停状态 + ImageIO 小缩略图缓存,滚动顺滑不卡顿

## 构建与运行

需要 Swift 6 命令行工具链(`xcode-select --install` 即可,无需完整 Xcode)。

```bash
./build.sh                 # 编译 + 拼装 ClipboardManager.app + ad-hoc 签名
open ClipboardManager.app  # 启动(菜单栏出现剪贴板图标,Dock 无图标)
```

首次启动若被 Gatekeeper 拦截(未公证):**右键 App → 打开**,或到 **系统设置 → 隐私与安全性** 点「仍要打开」。

退出:点菜单栏图标 → 右键(或 Control 点击)→ **退出剪贴板历史**。

## 使用

| 操作 | 方式 |
| --- | --- |
| 唤出历史 | `⌘⇧V`,或左键点菜单栏图标 |
| 搜索 | 直接键入关键字(匹配内容 / 文件名 / 来源 App) |
| 选择 | `↑` / `↓` |
| 选用(自动粘贴 / 仅复制) | `↵`,或左键点条目 |
| 删除选中项 | `⌫`(搜索框为空时);或右键 → 删除 |
| 关闭 | `esc` |
| 置顶 / 复制 | 右键条目 → 菜单 |
| 菜单(自动粘贴 / 开机启动 / 清空 / 退出) | 右键菜单栏图标 |

选用一条后:若开启了「选中后自动粘贴」(默认),会自动粘进当前窗口;否则只写回剪贴板,焦点交还上一个 App,你按 `⌘V` 粘贴。

## 自动粘贴与权限

「选中后自动粘贴」通过合成 `⌘V` 实现,需要 macOS **辅助功能(Accessibility)** 授权:

1. 首次选用条目(或在菜单勾选该项)时会弹出引导 → **打开系统设置 → 隐私与安全性 → 辅助功能**。
2. 勾选 **ClipboardManager**(若列表没有,点 `+` 添加这个 `.app`)。
3. 回到 App 重试即可自动粘贴。

不想授权?在菜单里关掉「选中后自动粘贴」,退回到「仅复制 + 手动 `⌘V`」,完全不需要任何权限。

## 自测

不依赖 GUI,验证存储逻辑(去重 / 移顶 / 容量淘汰 / 持久化往返 / 图片哈希去重):

```bash
ClipboardManager.app/Contents/MacOS/ClipboardManager --selftest
```

## 手动验收清单

1. `open ClipboardManager.app` → 菜单栏出现图标、Dock 无图标。
2. 在别的 App 复制文本 / 图片 / 文件 → `⌘⇧V` → 列表能看到,且带来源 App 与时间。
3. 键入关键字过滤;`↑↓` 选择。
4. 授权辅助功能后,在文本框里 `⌘⇧V` → 选一条 `↵` → **直接粘进**该文本框。
5. 关掉「自动粘贴」后,选一条 → 仅写回剪贴板,手动 `⌘V` 可粘贴。
6. 从密码管理器 / 密码框复制 → **不**出现在历史。
7. 右键某条 → 置顶 → 它固定在「置顶」段且不被淘汰。
8. 选中一条按 `⌫`(搜索框为空时)→ 该条删除,选中态落到下一条。
9. 复制大量内容(含若干图片)后上下滚动 → **顺滑不卡顿**。
10. 退出后重新 `open` → 历史仍在。

## 配置

代码内常量可改:

- 快捷键:`HotKey.swift` 的 `keyCode` / `modifiers`(默认 `kVK_ANSI_V` + `cmd|shift`)。
- 历史容量:`HistoryStore(maxItems:)`,在 `AppDelegate.applicationDidFinishLaunching` 调整(默认 200)。
- 轮询间隔:`ClipboardMonitor.start(interval:)`(默认 0.5s)。

## 项目结构

```
Package.swift                 SwiftPM 清单(刻意用 tools 5.9 → Swift 5 语言模式)
Info.plist                    LSUIElement / bundle id 等
build.sh                      编译 + 拼装 .app + ad-hoc 签名
Sources/ClipboardManager/
  main.swift                  入口(.accessory 启动;--selftest / --makeicon / --debug-show 分支)
  AppDelegate.swift           状态栏图标、菜单、装配
  ClipboardItem.swift         数据模型 + Codable + 去重键
  ClipboardMonitor.swift      轮询 NSPasteboard,过滤敏感项
  HistoryStore.swift          内存 + 磁盘持久化、去重 / 置顶 / 容量 / 写回剪贴板
  HotKey.swift                Carbon 全局快捷键(无需权限)
  AutoPaster.swift            合成 ⌘V 自动粘贴 + 辅助功能权限检查/申请
  PopupPanel.swift            无边框圆角半透明浮动面板
  HistoryView.swift           SwiftUI 列表 + 独立行 ClipRow(行内悬停)+ 自定义搜索框
  IconGenerator.swift         CoreGraphics 程序化绘制 App 图标(--makeicon)
  SelfTest.swift              --selftest 的存储逻辑断言
```

> 隐藏调试开关 `--debug-show`:塞入样例数据并立即弹出面板,仅供截图/可视化验证,正常使用不会触发。

## 已知限制

- 本地构建为 **ad-hoc 签名**(未公证):首次启动需手动放行(见上)。每次 `build.sh` 重新签名后可能需要再次放行。
- **自动粘贴** 需「辅助功能」权限;**注意**:ad-hoc 签名的本地构建每次 `build.sh` 重新签名后,系统可能视为新身份,需要到「辅助功能」里**重新勾选**(或先移除旧条目再加回)。不想折腾就关掉自动粘贴用手动 `⌘V`。
- **开机启动** 使用 `SMAppService.mainApp`;为稳定注册,建议把 `ClipboardManager.app` 移到 `/Applications` 后再开启。未签名 / 不在标准位置时该功能可能不可用(会弹错误提示,不影响其它功能)。
- 图片以 PNG 落盘在 `~/Library/Application Support/ClipboardManager/images/`;清空历史会一并删除。
